# Siri-LLM

Siri-LLM is a custom Large Language Model (LLM) tokenizer project developed using domain-specific organizational data from iSignal.

This project is designed to process natural language queries and support AI-based services related to telecom, wireless communication, and AI technologies.

---

## Features

- Custom BPE tokenizer training
- Domain-specific corpus processing
- Telecom and AI focused dataset
- Tokenization testing
- Hugging Face tokenizer integration

---

## Technologies Used

- Python
- Hugging Face Tokenizers
- BeautifulSoup4
- Requests
- Jupyter Notebook
